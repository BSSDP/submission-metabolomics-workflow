# Analysis card

## Analysis ID
M05

## Question
Which annotated features yield a clean, nonredundant metabolite-level matrix?

## Method
InChIKey or normalized-name/formula identity, annotation-quality ranking,
within-mode deduplication, exact overrides, and reversible exclusion audit.

## Outputs
Normalized/ranked/curated mappings, review queues, filtering figures, common-name
matrices, stable-ID lineage, and session information.

## Caveat
Drug, contaminant, and endogenous-metabolite boundaries require expert review.
