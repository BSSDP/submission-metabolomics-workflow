# Analysis card

## Analysis ID
M03

## Question
How are biological samples and features structured globally and by group?

## Method
Row z-scoring, configured clipping, hierarchical clustering, clinical column
annotations, and optional within-group column clustering.

## Outputs
Standalone heatmaps, displayed matrices, annotations, and clustering settings.

## Caveat
Top differential heatmaps reuse discovery data and are descriptive.
