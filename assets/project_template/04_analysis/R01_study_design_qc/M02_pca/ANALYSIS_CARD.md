# Analysis card

## Analysis ID
M02

## Question
Do positive- and negative-ion profiles show stable pooled QC and biological
structure?

## Method
Configured missingness filtering, half-minimum imputation, total-signal
normalization, log2 transform, Pareto scaling, PCA, and confidence ellipses.

## Outputs
Separate QC-inclusive and biological-only PCA figures by ion mode, scores,
variance, retained features, and QC CV.

## Caveat
PCA separation is descriptive and does not establish classification validity.
