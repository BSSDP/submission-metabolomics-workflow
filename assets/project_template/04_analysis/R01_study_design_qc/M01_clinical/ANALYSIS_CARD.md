# Analysis card

## Analysis ID
M01

## Question
What are the cohort and clinical characteristics?

## Inputs
Configured clinical metadata; one row per biological sample.

## Method
Three-line Table 1, Wilcoxon tests for continuous variables, and
Fisher/chi-square tests for categorical variables as appropriate.

## Outputs
Table source, formatted workbook, standalone clinical plots, source data, log,
and session information.

## Caveat
Variables defined only in a subset must use that subset as the denominator and
state the eligibility rule in the table footnote.
