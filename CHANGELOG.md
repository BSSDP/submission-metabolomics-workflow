# Changelog

## v0.3.1 (2026-07-26)

- Created a metadata-only archival release after enabling Zenodo-GitHub
  integration. Workflow code and public package contents are unchanged from
  v0.3.0.

## v0.3.0 (2026-07-26)

- Prepared the first fixed public release.
- Added repository-level documentation, citation metadata, environment
  specifications, a hybrid discovery-to-targeted diagnostic example and a
  release checksum manifest.
- Documented model-development safeguards from applied plasma-metabolomics
  workflow development: finite candidate comparison, repeated nested
  resampling, fold-wise covariate sensitivity analysis, model locking,
  fixed-threshold reporting and separation of exploratory clinical integration
  from independent validation.

## Earlier development

- Established the project template, analysis contracts, curation rules and
  validation utilities for submission-oriented metabolomics studies.
