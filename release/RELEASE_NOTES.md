# Fixed public release: v0.3.1

This directory records the immutable public release of the reusable workflow
resource. It is intentionally distinct from study-specific analysis code and
participant-level data. This metadata-only archival release has unchanged
workflow content relative to v0.3.0.

## Included release guarantees

- repository version identifier;
- root README and citation metadata;
- reference Python environment specification;
- example hybrid discovery-to-targeted diagnostic configuration;
- template, scripts and methodological contracts; and
- SHA-256 checksum manifest.

## Release procedure

1. Verify the checksum manifest after packaging.
2. Upload this release unchanged for peer review or public reuse together
   with any study-specific analysis code package.
3. Create a public archive from the same release and add the resulting Zenodo
   DOI to `CITATION.cff` and the repository record.
4. Do not amend this release after review. Create a new version and manifest
   for any change.
